Public website, bug reports and feature requests for Bastion Brawl.
This repository does **not** contain the game's source code, private assets,
credentials or deployment configuration.

## Feedback / Segnalazioni

English and Italian are welcome. Search existing issues before opening a report.
GitHub issues are public: never post passwords, tokens, save files, purchase
receipts, email addresses or other personal information. Redact attachments.
Suggestions are not commitments to a release date or a particular implementation.

Puoi scrivere in inglese o italiano. Cerca prima tra le segnalazioni esistenti.
Le issue sono pubbliche: non pubblicare password, token, salvataggi, ricevute,
indirizzi email o altri dati personali. Oscura i dati sensibili negli allegati.
Le proposte non costituiscono impegni di rilascio.

## Website maintenance

The site is a standalone `index.html`, with automatic English/Italian selection,
manual language buttons and system light/dark theme. It uses no build tools,
external scripts, analytics or cookies. GitHub Pages publishes the root of `main`.
Edit the public files and push to `main` to update the site.

The canonical advertising authorization file is at the **hostname root**:
<https://pamontag-org-ghe.github.io/app-ads.txt>, maintained in
<https://github.com/pamontag-org-ghe/pamontag-org-ghe.github.io>.
The copy in this project must stay identical to that file. AdMob ignores the
`/bastionbrawl-public/` path when discovering `app-ads.txt` from the developer
website URL, so the project-level copy alone is insufficient.

Use `https://pamontag-org-ghe.github.io/bastionbrawl-public/` as the Google Play
developer website. Keep the dedicated privacy and deletion URLs above for those
separate store fields. Public store association and AdMob verification are
separate from publishing these files; website deployment does not enable ads.
